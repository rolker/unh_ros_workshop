# Day 3 of the ROS Bootcamp

Since the robots run ROS 2 Humble, we are targeting that distribution to avoid communication issues when we start working with the real robot.
One approach which has been implemented in this repository to run ROS 2 Humble on Ubuntu 24.04 is to build it from source. To avoid the python virtual environment difficulties, the vision tutorials have been reimplemented in C++ in this workspace.

## ROS2 Actions

Today's focus was on ros actions.

Start with code from this repo: https://github.com/olaghattas/unh_ros_bootcamp_ws, which has been included in ./day3/

Follow the tutorial in ./day3/unh_ros_bootcamp_ws/src/action_tutorial/README.md
